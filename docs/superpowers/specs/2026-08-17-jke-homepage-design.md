# JKE 홈페이지 첫 페이지 전면 개편 — 설계 문서

작성일: 2026-08-17
대상: http://www.jke.kr/ 메인 페이지 (첫 페이지 한정)

## 1. 배경

㈜제이케이이(JKE)는 2002년 설립된 선박·해양플랜트·산업용 전기 배전반 제조사다.
부산 강서구 미음산단 소재. 현행 웹사이트는 2016년 제작으로 다음 문제를 안고 있다.

- 뷰포트 `width=1100px` 고정 — 모바일 대응 없음
- 본문 텍스트가 전부 PNG 이미지 — 검색 노출·접근성·번역 모두 불가
- jQuery 1.11 + TweenMax + jquery.cycle 기반의 낡은 슬라이더
- 회사가 보유한 강력한 자산(2002년부터의 실제 연혁, 국제 인증, 글로벌 파트너십)이
  게시판 안에 묻혀 있어 첫 화면에서 전혀 드러나지 않음

## 2. 목표

첫 페이지 하나로 "이 회사는 24년간 선박·해양 전기 시스템을 만들어 온 검증된
제조사"라는 인상을 스크롤 한 번에 전달한다. 성공 기준:

- 스크롤을 끝까지 내리는 동안 끊김 없는 하나의 시퀀스로 읽힐 것
- 표기하는 모든 수치·연혁이 실제 확인된 사실일 것 (허구 수치 금지)
- 모바일에서 정상 동작하고, `prefers-reduced-motion`에서 안전하게 정지할 것
- 초기 전송량 2MB 이하

명시적 비목표: 서브페이지 6개, 다국어 토글, CMS 연동, 게시판 이관.

## 3. 기술 스택

| 항목 | 선택 | 근거 |
|---|---|---|
| 빌드 | Vite | 에셋 해싱·압축·dev server. 프레임워크 없이 정적 산출 |
| 마크업 | 순수 HTML | 1페이지에 컴포넌트 추상화 불필요 |
| 애니메이션 | GSAP 3.13 + ScrollTrigger | 3.13부터 전 플러그인 무료. 스크럽 제어 정밀도 |
| 스무스 스크롤 | Lenis | ScrollTrigger와 공식 연동 경로 존재 |
| 배포 | Netlify | 정적 호스팅, `netlify.toml` 빌드 |

검토 후 탈락: Astro(서브페이지 확장 전엔 과함), React/Next(과잉).

```
--bg        #07090C   페이지 바탕
--surface   #0E1216   카드·패널
--line      #1B2228   경계선

```

액센트는 히어로 언더라인, 섹션 인디케이터, 호버 상태에만 쓰고 화면 면적 3%를 넘기지
않는다. 다크 화면의 그라디언트 밴딩을 없애기 위해 전면에 필름 그레인 오버레이를 깐다.

타이포: 영문 헤드라인은 좁고 무거운 그로테스크(가변 폰트), 국문은 Pretendard Variable.

## 6. 에셋 파이프라인

- Higgsfield로 히어로 루프영상 1개 + 정지컷 17장 생성
  (씬 배경 8장, 제품 컷 9장)
- Stitch MCP는 레이아웃·디자인시스템 레퍼런스 스크린 생성 용도로만 사용한다.
  스크롤 연출은 Stitch 출력물로 표현할 수 없으므로 실제 코드는 GSAP로 직접 작성한다.
- 모든 AI 생성물은 `public/assets/ai/`에 격리하고 README에 **실사진 교체 대상**임을
  명시한다. 실제 JKE 제품 사진이 확보되면 동일 파일명으로 교체하면 된다.

## 7. 성능·접근성

- 히어로 영상에 `poster` 지정. `<768px`에서는 영상을 로드하지 않고 정지컷으로 폴백
- `prefers-reduced-motion: reduce`에서 ScrollTrigger 스크럽·pin 전부 해제, 페이드만 유지
- 이미지는 AVIF/WebP 우선, `loading="lazy"`, 히어로 포스터만 preload
- 시맨틱 heading 위계 (h1 1개, 섹션당 h2), 키보드 포커스 링 유지
- 상단 네비의 기업소개·사업분야·제품소개·R&D·PARTNER·고객지원은 현행 jke.kr 실제 URL로
  연결한다 (첫 페이지만 개편하는 스코프이므로)

## 8. 배포

`netlify.toml`에 `command = "npm run build"`, `publish = "dist"`.
`_headers`로 해시된 에셋에 장기 캐시 지정. 사이트명 `jke-kr`.
